## Methodology & limits
- Every claim carries a named benchmark, a number, a date, and a primary URL opened during this refresh (2026-11-08). Headline numbers were re-fetched and read off the page by the editor, not filled from memory.
- Self-reported numbers are labelled; third-party / reproducible evals (Artificial Analysis runs its own) are preferred. Vendor self-reports run materially above standardised harnesses — never cross-compare the two.
- **No index rebase this week.** The Artificial Analysis Intelligence Index reads **v5.0.1** on every model page this session — a CritPt-v2 robustness regrade of v5.0, not a scale change — so this week's Index numbers are directly comparable to last week's v5.0 numbers (last week's v4.3.2→v5.0 rebase is complete and behind us).
- **Movement this week.** (1) **New open-weight #1:** Kimi K3.1 Pro debuts at Index 46, 13 points clear of #2 DeepSeek V4.1 Flash 1017 (33, up from 32); Ling 3.1 Flash 1019 ticked 29→30; Inkling (Xhigh) fell off the open-source board (no number this session). (2) **Multimodal flipped:** Gemini 4 Carbon (Medium) took MMMU-Pro #1 at 89%, Opus 5.5 to #2 at 88% (one rounded point apart — near-tie). (3) **Fastest dropped:** AA's per-provider output-speed leaderboard shows no data this session after the Performance Benchmarking v3.0.0 change; the 1,767 t/s Cerebras figure can't be re-verified, so the row is dropped. Coding, reasoning, long-context, agentic and cheapest-capable leaders held on their own (non-Index) metrics.
- **Open-weight licence watch — the #1 is NOT MIT.** The new open leader, **Kimi K3.1 Pro (46)**, ships under a bespoke "Kimi K3.1-Pro Licence." The **highest-Index MIT** open model is **DeepSeek V4.1 Flash 1017 (33)**, with MiMo-V2.6-Pro (30) and Ling 3.1 Flash 1019 (30) also MIT. GLM-5.3 (32), MiniMax-M3.1-Flash (29), Mistral Large 4 (26) and Muse Spark Open (25) ship under bespoke licences. Rows rank on the independent AA Index but flag licence and provenance — read the licence before deploying.
- **Saturation watch:** GPQA Diamond (~94% top cluster) and τ²-Bench Telecom (~99%) have largely saturated; AIME 2025/2026 are at/near a perfect score for top models. Where a flagship bench has saturated, this file leads with a still-discriminating eval (HLE for reasoning, Terminal-Bench Hard for agents).
- **Stated context window ≠ usable context.** The long-context row cites a multi-needle retrieval eval at depth, not a spec-sheet number; advertised 1M (and larger) windows degrade sharply before their stated limit (Gemini 3.1 Pro: 84.9% at 128k → 26.3% at 1M). Newer 1M-window models (Claude Opus 5.5, and the open 1M models Kimi K3.1 Pro, MiMo-V2.6-Pro, DeepSeek V4.1 Flash 1017, Ling 3.1 Flash 1019) publish no comparable 1M multi-needle number this session, so Opus 4.6's 76% remains the strongest *published* figure.
- **Cheapest-capable is time-of-day-dependent — for the runner-up.** The #1 GPT-6 Luna is a flat $0.10/$0.50. The #2, DeepSeek V4.1 Flash 1017, bills peak/off-peak (off-peak input cache-miss $0.15 / output $0.60; peak $0.30/$1.20), so whether it ever beats Luna depends on the UTC hour and the workload's input/output mix — and even off-peak it sits above Luna's flat rate, so Luna keeps #1 despite DeepSeek's higher v5.0.1 Index (33 vs 28) and MIT weights.
- **A benchmark leaderboard can go dark — and when it does, the row drops.** The Fastest row has no number this refresh because AA's per-provider output-speed data is unavailable this session (Performance Benchmarking v3.0.0).
